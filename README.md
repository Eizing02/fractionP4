# ครัววุ้นเศษส่วน ป.4 (Fraction Jelly Lab)

สื่อการเรียนรู้ออนไลน์เชิงโต้ตอบ วิชาคณิตศาสตร์ ป.4 (ตัวชี้วัด **ค 1.1 ป.4/13**) เรื่อง **การบวกและการลบเศษส่วนที่ตัวส่วนตัวหนึ่งเป็นพหุคูณของอีกตัวหนึ่ง** ออกแบบให้ใช้งานง่ายที่สุด ปุ่มน้อย เข้าใจจากภาพได้ทันที

## จุดเด่นของสื่อ
- **2 โหมดเข้าใจง่าย:**
  1. **`เรียน`** — เล่นจบใน 2 จิ้ม: จิ้มปุ่ม **`หั่นแบ่งชิ้น`** ทีละขั้นจนชิ้นเท่ากัน $\rightarrow$ จิ้ม **`รวมชิ้นวุ้นเลย`** หรือ **`ตักวุ้นออกเลย`** (มีปุ่ม **`ตั้งโจทย์เอง`** ซ่อนไว้สำหรับครูใช้สอนหน้ากระดาน)
  2. **`เล่นเกม`** — ลูกค้าสัตว์น่ารักมาสั่งออเดอร์วุ้น มีตัวเลือกใหญ่ ๆ แค่ 3 ตัวเลือก ไม่ซับซ้อน พร้อมสะสมสติกเกอร์วุ้นดาว
- **รองรับทั้งการบวก (`+`) และการลบ (`−`)** พร้อมภาพเปลี่ยนแบบเรียลไทม์ทุกจังหวะ
- **ภาพเปรียบเทียบในตัว:** เทียบขนาด **1 ชิ้น** ซ้าย-ขวา + ปุ่ม **เทียบก่อนหั่น ↔ หลังหั่น** พิสูจน์ว่าปริมาณเนื้อวุ้นเท่าเดิม
- **วิธีทำทีละขั้น** ซิงก์สีและตัวเลขตรงกับภาพแบบเรียลไทม์ พร้อมแปลงจำนวนคละ/อย่างต่ำให้อัตโนมัติ
- **โจทย์ไม่ซ้ำกัน & พอดีระดับ ป.4:** สุ่มแบบ Shuffle Bag 3 ระดับ (ไต่ระดับอัตโนมัติ) และการลบไม่ติดลบ

## วิธีเปิดใช้งานบน GitHub Pages (3 ขั้นตอน)

1. สร้าง Repository ใหม่บน GitHub และอัปโหลดไฟล์ในโฟลเดอร์นี้ (`index.html`, `css/`, `js/`, `assets/`, `README.md`) ขึ้น branch `main`:
   ```bash
   git init
   git add index.html css js assets README.md
   git commit -m "Add Fraction Jelly Lab Grade 4 web app"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo-name>.git
   git push -u origin main
   ```
2. ไปที่ **Settings** → **Pages** ใน Repository บน GitHub
3. เลือก **Source:** `Deploy from a branch`, **Branch:** `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/<repo-name>/` พร้อมสร้าง QR Code ให้นักเรียนเปิดเล่นได้ทันที
